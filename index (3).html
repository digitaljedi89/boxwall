BoxTrack

QR Box Inventory + LED Locator — one-time setup

1
Create a free Supabase project

Go to supabase.com → Sign up → New Project. Wait ~1 min for it to provision.

2
Run this SQL in the SQL Editor
create table boxes ( id text primary key, name text not null, description text, items jsonb default '[]'::jsonb, zone_id text, pin_number integer, created_at timestamptz default now() ); create table zones ( id text primary key, name text not null, mqtt_topic text, color_index integer default 0, created_at timestamptz default now() ); create table led_state ( box_id text primary key, is_on boolean default false, updated_at timestamptz default now() ); alter table boxes enable row level security; alter table zones enable row level security; alter table led_state enable row level security; create policy "Public all" on boxes for all using (true) with check (true); create policy "Public all" on zones for all using (true) with check (true); create policy "Public all" on led_state for all using (true) with check (true);
3
Get your API keys

Project Settings → API → copy the Project URL and anon/public key.
